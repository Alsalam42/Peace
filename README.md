Behind the scenes

Channel popups: Clicking a channel's button opens a popup with its logo, name and an "Open channel" link. The links and logos for the three channels are set in one small block of code, so they are easy to change.
Icons: All icons are drawn into the page itself, so there is nothing to load from outside.
Videos: The six videos play only when someone presses play.
